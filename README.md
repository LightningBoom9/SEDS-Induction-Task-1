# SEDS-Induction-Task

My name is Krishna Karthik Vadavalli. ID no-2026B5PS1249H. This is the avionics induction task for the SEDS in BITS Pilani, Hyderabad. Contains a state machine and a graph coded with python. 

Task 1: Used pandas instead of csv module since  pandas builds a data frame and auto detects numbers as int/float while csv module takes them as strings and they'd have to be manually converted to floats. There were corrupted data in the data sheet which has been dealt with. Used errors="coerce" to convert what it can to float/int and the rest to NaN instead of it crashing. For erratic values present in the depth data sheet, i used rolling median with a window of 5 with the selected value at the center(2 to the left and 2 to the right). Median can't be dragged much by a wild outlier but can drag mean. I checked the deviation between the suggested value and the actual value and if it was more than 50 units, converted it to NaN and extrapolated a straight line between two present points. Used rolling mean with a window of 5 to clean random jitter after taking the median values in the place of outliers to make the graph look clean. Used this altered data points to plot an animated graph and a normal graph showing two line comparing between raw and smoothed data.

Task 2: Created a states system using Arduino and other components in tinkercad and coded it accordingly. Had no prior knowledge regarding this but used Claude to teach myself the code required for this project. Initially wrote down the logic for the task(entering conditions, leaving conditions and outputs while in the state). Later used cases in loop using if/else statements to switch between states as the situation demanded in the provided enter/leave conditions. In the case where both storm and Charybdis occur, I gave priority to Charybdis. Used unsigned long for time since it can hold larger values than int. Faced a problem with the light sensor and the button which turned out to be wiring errors which were corrected using google searches looking at the wiring. Faced a problem with the LCD screen since I was using one variant while the code was for other. I went through the options of the screen and chose the right model.
